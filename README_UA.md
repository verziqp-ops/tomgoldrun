# Tom Run Pilot 0.1 — ЕКСПЕРИМЕНТАЛЬНИЙ ВИХІДНИЙ ПРОЄКТ

Версія 0.3 виправляє поріг переходу за одним золотим предметом, налаштовує
раніший обхід і оптимізує обчислення кореляції.
Версія 0.2 виправляє блокування жестів при повільному розпізнаванні,
визначення активної гри з порожнім деревом інтерфейсу та прискорює пошук
шаблонів. На панелі додано тестові свайпи й статус виконання жестів.
Версія 0.1 успішно зібрана через GitHub Actions, але користувач повідомив,
що авто не рухається. Версія 0.2 зібрана; тестові жести працюють на телефоні, але користувач
повідомив про бездіяльність авто при видимих об’єктах. Версія 0.3
потребує перевірки автоматичного керування на телефоні.

Після встановлення оновлення увімкни службу спеціальних можливостей,
захоплення екрана та в грі натисни «Тест RIGHT». Якщо персонаж рухається,
працює канал жестів — далі натисни «Авто». Якщо не рухається, зніми панель
повідомлень: вона покаже відмову, скасування або невизначену активну гру.
Тестові кнопки призупиняють автоматичне керування.

## Що реалізовано

- MediaProjection: отримання екрана лише після системного дозволу.
- AccessibilityService: свайпи лише коли активна Talking Tom Gold Run.
- Нижня панель: Авто/Пауза, вибір режиму, Стоп. Авто спочатку вимкнено.
- Чотири режими: земля, політ, наземний бос, повітряний бос.
- Експериментальний пошук зображень золота, синіх предметів, бомбочок,
  перешкод, арок, бочок, боса та реактивного ранця за вирізками твого відео.
- Бомбочки мають високий пріоритет у бою, але небезпечні доріжки важливіші.
- Арки обходити. У польоті немає стрибків або підкатів.
- Підтвердження об'єктів у двох кадрах, оцінка наближення, пауза між жестами.
- Корекція доріжки за положенням персонажа, коли його впевнено впізнано.
- Відключення авто при виході з гри, зупинка при завершенні захоплення.
- Немає INTERNET-дозволу, хмарного аналізу або записування екрана на диск.

## Дуже важливі межі прототипу

Це НЕ навчена нейромережа та НЕ перевірений бот для довгих забігів.
Шаблони отримані вручну з одного наданого відео. Вони не охоплюють усі
локації, моделі транспортних засобів, ракурси, розміри, персонажів і ефекти.
Незнайомі текстури можуть не розпізнаватися, а схожі ділянки — розпізнаватися
помилково. Автопілот не розуміє повну геометрію світу, прірви, маршрути по
дахах, магніт, всі анімації та всі переходи. Арки з відео представлені
прикладами; універсальне блокування всіх порталів не підтверджене.

Правила рішень перевірені окремо від зору. Вони можуть працювати правильно
на заданих даних, а в реальній грі отримати помилкові дані від розпізнавання.
Перевірка на кадрах, з яких вирізані шаблони, не доводить, що інші кадри
будуть розпізнані. Немає гарантії уникнення зіткнень чи нескінченної гри.

Перед авто спочатку подивись на повідомлення панелі. Вибери режим вручну,
якщо автоматичне розпізнавання помиляється. У польоті для переходу між
доріжками передбачені горизонтальні свайпи; їхню дію потрібно перевірити.
Після поразки натисни Пауза: розпізнавання меню й автоматичний перезапуск
не реалізовані. Реклама всередині гри може не змінити активний пакет, тому
на час реклами також став Пауза.

## Збірка APK

Потрібні JDK 17, Android SDK Platform 35, Gradle 8.9. Відкрий цю папку
в Android Studio, дочекайся синхронізації й обери Build APK(s).
Або виконай `gradle :app:assembleDebug` із кореня проєкту.
Результат: `app/build/outputs/apk/debug/app-debug.apk`.
Gradle Wrapper у проєкті відсутній; використовуй встановлений Gradle 8.9
або додай Wrapper через Android Studio.

Є `.github/workflows/build-apk.yml`: якщо покласти ВМІСТ папки TomRunPilot
в корінь GitHub-репозиторію, Actions може зібрати APK. Цей workflow
підготовлений, але тут не запускався. Він завантажує інструменти Android
і Gradle та віддає debug APK як artifact. Не завантажуй у репозиторій своє
повне відео — для збірки воно не потрібне.

Для збірки з телефона без розпаковування файлів дивись PHONE_BUILD.md.

## Запуск після успішної збірки

1. Встанови APK. Відкрий Tom Run Pilot.
2. Увімкни службу Tom Run Pilot у Спеціальних можливостях.
   Для вручну встановлених APK Android може потребувати «Дозволити
   обмежені налаштування» в меню інформації про застосунок.
3. Натисни «Захоплення екрана» й дай системний дозвіл. Потрібен весь екран,
   портретна орієнтація, стандартний масштаб. Перший прототип налаштований
   під співвідношення сторін наданого запису 1080×2340.
4. Відкрий гру, почни забіг вручну. Панель знаходиться знизу.
5. Спочатку режим «Перегляд»: жестів немає. Повідомлення показує режим,
   кількість підтверджених об'єктів, оцінку доріжки й рішення.
6. Натисни Авто для короткого пробного забігу. Пауза вимикає жести,
   Стоп завершує захоплення. При переході в інший застосунок авто
   вимикається й не вмикається самостійно після повернення.

## Перевірки

На JDK 17 виконано:
- 28 перевірок Planner: збирання бомбочок і синіх предметів, пріоритет
  перешкод, обходи арок, відсутність вертикальних жестів у повітрі,
  cooldown, корекція доріжки, уникнення перетину небезпечної середньої смуги.
- Перевірки RgbMatcher: інваріантність до зсуву яскравості, відхилення
  однотонного фрагмента, 4800 граничних вікон без виходу за межі.
- TemplateAudit: пошук 10 прикладів у вихідних кадрах. Це smoke test
  числового ядра, не оцінка точності на незалежному відео.

Не виконано: Android-білд, інсталяція, MediaProjection/Accessibility
на реальному телефоні, замір швидкості Pixel 7 Pro, довгий забіг,
перевірка всіх моделей транспорту, точність і кількість хибних спрацювань.

Перевірки можна повторити, скомпілювавши Planner.java, RgbMatcher.java
і tests/*.java через javac. TemplateAudit додатково потребує зменшених
360×780 кадрів s01.jpg..s20.jpg зі свого відео; ці кадри не включені.
Маніфест, XML-ресурси та наявність шаблонів перевірені локально.

## Подальша робота

Щоб отримати стабільний автопілот, потрібні незалежні записи з розміткою
перешкод і предметів у всіх потрібних режимах, перевірка точності
розпізнавання та реальні забіги. Наступний крок — легка модель виявлення
об'єктів і трекер, а також окреме розпізнавання меню/поразки й динамічної
швидкості. У цьому архіві такої навченої моделі немає.

Шаблони: app/src/main/assets/templates. Координати ручних вирізок:
tests/template-provenance.csv (часи приблизні для дискретизації fps=1/8).
