# Режим навчання 0.8

Це експериментальна нейромережа Double DQN, яка оновлюється на телефоні під час спроб. Це ще не навчений автопілот; надійне уникнення перешкод не продемонстроване.

## Як запустити

1. Встанови APK, увімкни службу спеціальних можливостей, почни захоплення саме гри.
2. Відкрий панель і натисни «Навчання: перемкнути». Дочекайся статусу «Навчання».
3. Почни забіг вручну, потім натисни «Увімкнути авто».
4. Після поразки додаток ставить паузу, якщо бачить підтримуваний екран SAVE ME. Для іншого екрана натисни «Зіткнення» до натискання «Пауза».
5. Почни наступний забіг вручну й натисни «Увімкнути авто». Не вмикай авто на меню: інакше меню потрапить до навчання як гра.
6. У польоті обери вручну FLIGHT або BOSS_AIR: ці режими забороняють стрибок і пригинання.

Спочатку дії частково випадкові, і зіткнень буде багато. Кількість оновлень та спроб показує роботу навчання, а не доведену якість гри. Немає встановленої кількості спроб, після якої бот гарантовано навчиться.

## Що реалізовано

- Чотири кадри області гри: кожен 20×28 пікселів у відтінках сірого, плюс код режиму. Обрізаються HUD і нижня панель; рамки вимикаються.
- Навчена з нуля мережа з одним прихованим шаром 24 нейрони tanh і п'ятьма оцінками дій. Це MLP, не велика CNN чи мовна модель.
- Double DQN, окрема цільова мережа, пам'ять останніх 256 переходів, Huber loss, дослідження з початковою ймовірністю 60%, що зменшується до 8%.
- Винагорода 0.05 за секунду активної гри та штраф −1 за позначену/виявлену поразку. Збір золота, бомби, портали й пошкодження без смерті окремо не оцінюються.
- У досвід входять тільки завершені Android-жести та дія «нічого». Відхилені жести не записуються як виконані.
- Модель, цільова мережа, досвід і статистика зберігаються кожні 15 секунд, на паузі, при поразці й штатному завершенні служби. Збереження атомарне; нещодавні зміни можуть загубитися при аварійному закритті.
- Дані зберігаються локально в приватних файлах додатка. Оновлення зі збереженням даних залишає навчання; видалення додатка очищає його. Дані не надсилаються назовні.

## Перевірка та межі

117 перевірок охоплюють навчання на двох простих станах, збереження/відновлення, пошкоджений файл, послідовність кадрів, завершення епізодів, відхилені жести й обмеження польоту. На 11 наданих кадрах підтримуваний екран SAVE ME визначений, 10 кадрів гри не позначені поразкою. Це розробницька перевірка, не незалежна оцінка всіх меню.

Тривалий забіг на реальному телефоні, здатність розпізнавати різні перешкоди, швидкість навчання й нагрівання не перевірені. Малий розмір мережі та пам'яті може обмежувати якість. Нинішній режим не виконує всі вимоги щодо золота, арок і босів.

## Досліджені приклади

- https://github.com/vedantpatel021/subway-surfers-reinforcement-learning — DQN з історією кадрів, replay buffer і збереженням. У коді перевірено environment.py та agent.py: керування клавіатурою на ПК, визначення смерті за пікселем; безпосередньо для Тома на Android не підходить.
- https://github.com/m4n4n-j/subway-surfers-AI-main — автори описують DQN/CNN; у README вказаний скромний результат і необхідність подальшого навчання.
- https://github.com/Bezet1/subway-surfers-ai — README описує CNN-підхід для Subway Surfers. Заявлений результат не був відтворений у цьому проєкті.
- https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html — пояснення replay memory та цільової мережі.

Код цих проєктів не скопійовано до APK. Реалізація написана на Java без стороннього ML runtime. Готової навченої моделі саме для Talking Tom Gold Run у виконаному пошуку не знайдено; це не доводить її відсутності всюди.
